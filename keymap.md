# Atalhos de janela — Linux × macOS

Os dois gerenciadores usam o mesmo esquema. Ao mudar um atalho, atualize os dois arquivos e esta tabela.

- Linux: `hypr/configs/Keybinds.conf` e `hypr/UserConfigs/UserKeybinds.conf` — modificador **Super**
- macOS: `macos/aerospace/aerospace.toml` — modificador **Alt (Option)**

| Ação | Hyprland | AeroSpace |
|---|---|---|
| Terminal | Super+Enter | Alt+Enter |
| Fechar janela | Super+Q | Alt+Q |
| Tela cheia | Super+Shift+F | Alt+Shift+F |
| Alternar flutuante | Super+Space | Alt+Space |
| Alternar divisão | Super+Shift+I | Alt+Shift+I |
| Focar | Super+setas | Alt+setas |
| Mover janela | Super+Ctrl+setas | Alt+Ctrl+setas |
| Redimensionar | Super+Shift+setas | Alt+Shift+setas |
| Ir ao workspace N | Super+1..0 | Alt+1..0 |
| Próximo / anterior workspace | Super+Tab / Super+Shift+Tab | Alt+Tab / Alt+Shift+Tab |
| Mover p/ workspace N e seguir | Super+Shift+1..0 | Alt+Shift+1..0 |
| Mover p/ workspace N sem seguir | Super+Ctrl+1..0 | Alt+Ctrl+1..0 |
| Launcher | Super+D (rofi) | atalho do Raycast |
| Recarregar config | — | Alt+Shift+R |
